# Security Policy

## Reporting a Vulnerability

If you discover a security vulnerability in FlickerX, please report it privately
by opening a security advisory at:

https://github.com/Omii-004/FlickerX/security/advisories/new

Do **not** report security issues via public GitHub issues.

## What to Expect

- Acknowledgment within 48 hours
- A fix timeline will be discussed based on severity
- You'll be credited for the discovery (unless you prefer to remain anonymous)

## Scope

- Backend API authentication and authorization logic
- JWT token handling and secrets
- User data privacy
- API key leakage
- Cross-site scripting (XSS) and CSRF protections
- Dependency vulnerabilities with known CVEs

## Out of Scope

- Theoretical attacks requiring physical access
- Social engineering
- Denial of service without demonstrable impact
- Issues in dependencies that are already patched in newer versions

## Responsible Disclosure

We kindly ask that you allow us reasonable time to fix and release a patch
before disclosing the vulnerability publicly.
